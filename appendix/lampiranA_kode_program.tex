\chapter{Kode Program}

Lampiran ini memuat \textit{source code} yang dibangun sebagai hasil implementasi model yang dikemukakan pada Bab 3.

\begin{lstlisting}[language=Python, basicstyle=\ttfamily\small, breaklines=true, frame=single, caption={Contoh cuplikan kode pelatihan model}]
def train(model, dataloader, optimizer, loss_fn, epochs):
    for epoch in range(epochs):
        for x_batch, y_batch in dataloader:
            optimizer.zero_grad()
            y_pred = model(x_batch)
            loss = loss_fn(y_pred, y_batch)
            loss.backward()
            optimizer.step()
    return model
\end{lstlisting}
